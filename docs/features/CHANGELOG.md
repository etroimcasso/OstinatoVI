- **2026-11-09** — `ai-scripts`: created ✅ complete. The 384 monster AI scripts as typed steps (`src/data/ai_scripts`): `AiStep` with a named builder for every action and each of the 29 conditions, `AiTarget`, `AiMonsters`, `AiVariable`, `AiSwitch`, `AiEffect`, and `AiScript` rows keyed by `MonsterId` with a turn part and a counter part.
