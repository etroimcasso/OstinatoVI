# Feature Changelog

Chronological feature state transitions, newest first.

- **2026-10-24** — `dialog-window`: created 🟡 in progress. The dialog window's logic lands (`src/text/dialog_window`): it opens over five frames and closes over five more, at the top or the bottom of the screen, with or without a box behind the text, and carries the map-title box. It places the text area and spaces its lines — 16 pixels apart while the box opens, 15 once it is open — and the text components (`DialogText`, `DialogCursor`, `DialogWipe`) take that spacing as a parameter. The dialog preview runs a window beside each message.
- **2026-10-24** — `build-system`: scope grown (stays ✅ complete). Twenty-third target `ostinato-vi-dialog-window-tests`; `src/text/dialog_window.cpp` joins the library.
- **2026-10-22** — `text-engine`: 🟡 in progress → ✅ complete. The developer preview `ostinato-preview-dialog <index>` (`tools/previews/dialog/`) plays messages from the installed cartridge with a scripted player — no input from anyone — in a window that closes itself after the last message, or with `--capture <dir>` with no window, writing every waiting page, a moved choice arrow and the first wipe step as images. Its screen, `DialogPreviewScreen`, is read back by four new cases. C++ baseline now **485/493/8** per platform.
- **2026-10-22** — `build-system`: scope grown (stays ✅ complete). Developer previews get their own home, `tools/previews/<name>/`, one target each; the first is `ostinato-preview-dialog`. None of their code is in the game binary. The field tick is `ostinato::kFieldTickPeriod`, and choosing the asset root moves into the library (`assets::configureAssetRoot`) so the game and every preview read the same cartridge.
- **2026-10-21** — `text-engine`: stays 🟡 in progress. The dialog font comes from the cartridge — glyph artwork, the width table and the choice arrow, the last two as new region rows (`FONT_WIDTH`, `DLG_CURSOR_GFX`) — and `src/text/font` builds the glyph and arrow sheets. The render layer lands (`src/render/`: `SpriteLayer`, `LayerOptions`, the depth and key table) with the dialog components `Glyph`, `DialogText`, `DialogCursor`, `DialogWipe` and `MapTitle`. The `text-engine` target grows to 87 cases. C++ baseline now **481/489/8** per platform; parser **953/953**.
- **2026-10-21** — all features: the code, file names and docs use American English throughout (`dialog`, `color`, `behavior`, …), including the text corpus's surface (`TextCorpus::dialog`, `tokenizeDialog`).
- **2026-10-10** — `text-engine`: created 🟡 in progress. The field dialog engine's logic lands (`src/text/`): the per-frame state machine, every control code, the English word wrap, the name/item/spell/gold splices, multiple choice, the page wipe and the map title, with no rendering type in it. New `ostinato-vi-text-engine-tests` target (49 cases; the Japanese-script run skips for want of a Japanese cartridge); every English message in the cartridge is driven to its end. C++ baseline now **443/451/8** per platform. `docs/Bugs.md` gains the margin-drop entry.
- **2026-10-10** — `build-system`: scope grown (stays ✅ complete). Nineteenth target `ostinato-vi-text-engine-tests`; `src/text/dialog.cpp` joins the library.
